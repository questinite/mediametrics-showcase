# MediaMetrics Showcase

MediaMetrics is an independently built portfolio project created to demonstrate analytics engineering, business intelligence, dashboard design, and full-stack data product development.

This repository is a public showcase and case study. It does not contain production source code.

## Live Links

- [View MediaMetrics Live Demo](https://mediametrics.questinite.site)
- [View Portfolio](https://questinite.site)

## What MediaMetrics Demonstrates

MediaMetrics demonstrates the ability to design, build, deploy, and explain a full-stack analytics product.

The project includes:

- Interactive marketing analytics dashboards
- API-driven KPI reporting
- Database-backed data exploration
- Campaign pacing and OTIF logic
- E-commerce ROI analysis
- Data masking and governance awareness
- Cloud deployment with HTTPS

## Dashboards

### 1. Media Analytics

A media performance dashboard covering spend, impressions, clicks, CTR, CPC, CPM, conversions, platform efficiency, brand concentration, trends, anomaly detection, and custom exploration.

### 2. Campaign Pacing

A campaign delivery dashboard focused on budget pacing, KPI delivery, OTIF health, client-level pacing, and campaign monitoring.

### 3. E-Commerce ROI

An e-commerce performance dashboard covering revenue, media cost, ROAS, marketplace comparison, campaign performance, and budget opportunity insights.
